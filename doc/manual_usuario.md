# Manual de usuario (borrador)

Este documento debe ser completado con capturas y ejemplos tras la validación de las vistas finales.

## Acceso y autenticación

-   Ingresar con usuario y contraseña.
-   Recuperar contraseña desde la pantalla de login.

## Funcionalidades principales

-   Gestión de normativas: crear, editar, buscar, eliminar.
-   Gestión de documentos: subir, versionar, descargar.
-   Alertas: configurar y visualizar alertas programadas.
-   Auditoría: consultar historial de acciones.

## Navegación

-   Menú superior para acceso rápido a módulos.
-   Mensajes de éxito/error tras cada acción.

## Soporte

-   Contactar al administrador para dudas o problemas de acceso.
